Add features in the Designer with custom attributes.

Paste one 3.5 KB (gzipped) script into Site settings. Then designers add behavior by setting custom attributes on elements in Webflow: CMS filtering and search with shareable URLs, first-touch UTM capture into form submissions, accessible inline validation, reading time, and copy buttons. The examples below use Webflow's own class names (w-dyn-list, w-dyn-item, w-form) and the actual production bundle.

Blog post 

    
Webflow's CMS is great for marketing teams. Developers usually step in when the site needs things the Designer doesn't offer natively: filtering a Collection List, keeping campaign attribution through a form, or stopping bad leads before they hit the CRM. This kit covers those cases with attributes that designers can set themselves, so developers stay out of the critical path. Each module has unit tests, fails safely, and works alongside Webflow's own scripts. The point isn't clever code. It's fewer tickets.

    
Launch offer: WEBFLOW25 

  


  

    
Install on a Webflow site

    
<!-- Site settings → Custom code → Footer code -->
<script defer src="https://cdn.jsdelivr.net/gh/mizcausevic-dev/webflow-attributes-kit@v1.0.0/dist/wf-kit.min.js"
        integrity="sha384-3GWkRtnlH7ttE452hlVKJGX9dDwxrf9Nv9iFE877+pTelIbJcDIxyjCop9ej3VPz" crossorigin="anonymous"></script>

    
Then select an element in the Designer → Settings → Custom attributes, and add for example wfk-list = work on the Collection List and wfk-field = industry on a text element bound to the Industry field. The README has the full attribute reference.
